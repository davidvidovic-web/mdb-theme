# Images Folder

Store theme-related images in this folder.

## Recommended Organization

```
images/
├── icons/          # SVG icons and small graphics
├── backgrounds/    # Background images
├── logos/          # Logo variations
├── placeholders/   # Placeholder images
└── ui/            # UI elements and graphics
```

## Image Optimization Tips

1. **Use appropriate formats**:
   - SVG for icons and simple graphics
   - WebP for modern browsers with fallbacks
   - JPG for photographs
   - PNG for images with transparency

2. **Optimize file sizes**:
   - Compress images before uploading
   - Use responsive images when possible
   - Consider lazy loading for better performance

3. **Naming conventions**:
   - Use descriptive, lowercase names with hyphens
   - Example: `hero-background.jpg`, `logo-dark.svg`
