# Hello Biz Child Theme

This is a child theme for the Hello Biz WordPress theme by Elementor Team.

## What is a Child Theme?

A child theme is a theme that inherits the functionality and styling of another theme, called the parent theme. Child themes are the recommended way of modifying an existing theme.

## Installation

1. Upload the `hello-biz-child` folder to your `/wp-content/themes/` directory
2. Activate the "Hello Biz Child" theme from your WordPress admin panel under Appearance > Themes
3. Make sure the parent theme "Hello Biz" is also installed

## Customization

### CSS Customizations
Add your custom CSS to the `style.css` file after the comment "Add your custom styles below this line"

### PHP Customizations
Add your custom PHP functions to the `functions.php` file after the comment "Add your custom functions below this line"

### Template Overrides
To override a template file from the parent theme:
1. Copy the template file from the parent theme's directory
2. Paste it into your child theme's directory
3. Modify the copied file as needed
